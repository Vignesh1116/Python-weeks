# Accept the positive integer n and display the cube of the number up to a given integer n
# in the following pattern using formatted string.

- ![alt text](image.png)

```python
n = int(input("Enter a positive integer: "))
for i in range(1, n + 1):
    cube = i ** 3
    print(f"{i}^3 = {cube}")
``` 
# Sample Input: 5
# Sample Output:    
# 1^3 = 1
# 2^3 = 8
# 3^3 = 27      
# 4^3 = 64
# 5^3 = 125
